# GOALIX V6 — Premium UI

Version visuelle de GOALIX basée sur la V5.

## Nouveautés
- Palette claire premium : blanc, bleu, vert et or.
- Nouveau système d'icônes SVG dans `components/Icons.tsx`.
- Badges d'équipes dans `components/Icons.tsx` via `TeamBadge`.
- Barre de coupon persistante en bas de l'écran via `components/CouponBar.tsx`.
- La sélection d'une cote reste clairement visible en vert/bleu.
- Le coupon affiche le nombre de sélections et la cote totale.
- Le lien du coupon permet de revenir au détail du match pour modifier une sélection.
- Alias TypeScript `@/*` corrigé dans `tsconfig.json`.
- Correction d'une apostrophe qui empêchait la compilation de `app/bets/page.tsx`.

## Important
Les logos affichés dans cette version sont des badges visuels temporaires. Pour la production, remplacer ces badges par les logos sous licence fournis par la source de données sportive.

Les matchs et cotes actuels restent des données de démonstration.
